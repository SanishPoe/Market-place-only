# MarketOnly

An unofficial Android app focused on Facebook Marketplace, with seller messaging through Messenger, saved listings, photo viewing, and on-device Smart Search. Not affiliated with Meta.

## Current audit build: 1.1.17

- Recycled Facebook links become visible again when their destination changes to Marketplace.
- The focus guard observes destination and navigation-label changes without rewriting Facebook's inline styles.
- Compact listing titles show up to two lines.
- Sign-out replaces the browser and removes account overlays, retained pages, pending file selection, and listing history. Late callbacks from the old page are rejected.
- Browser fixtures run with an installed Playwright browser or `TEST_CHROME`; build and regression checks are automated in GitHub Actions.

## Install the test app

Open **Actions → Build and verify MarketOnly → latest successful run**, then download **MarketOnly-1.1.17-test**. Extract the ZIP and tap `MarketOnly-1.1.17-test.apk`. If requested, allow your browser or Files app to install it.

The debug build has application ID `au.sutto.marketonly.dev` and label **MarketOnly Test**. It installs beside your working MarketOnly app and has its own Facebook session and local history. Keep your working app installed. Test builds use a debug signing key generated by CI; later test builds may need the test app removed first. Removing the test app does not remove the separate original app.

## Build and verification

GitHub Actions installs JDK 17, Gradle 8.9, Android SDK 35, and Playwright. It runs standalone Java and lifecycle checks, browser fixtures, Smart Search storage checks, builds the test APK, and validates its signatures and resource layout. Downloadable logs and screenshots are provided as a separate artifact.

Local controlled checks: `python3 tests/run_checks.py`. Browser checks: `npm install`, `npx playwright install chromium`, then `python3 tests/run_checks.py --browser`. On a machine with Chromium already installed, set `TEST_CHROME` to its executable. Use JDK 17 or later. Native builds require SDK platform 35 and build tools 35.0.0.

For a production update to an installed release, use application ID `au.sutto.marketonly`, version code 20, and the original signing key. That private key is not included. Never commit signing keys or passwords. The manual release builder and its signing instructions are described in README.txt.

## Limits and privacy

Controlled fixtures are not Android-device or authenticated Facebook acceptance tests. Facebook controls login, listings, selling, and messaging. The app blocks known feed/Reels/Watch routes; it is not a parental-control boundary and some seller/account Facebook pages remain reachable. External apps are outside its navigation restriction.

Only Internet permission is requested. No custom backend or analytics SDK. Facebook receives its normal website traffic. Smart Search stores a bounded local catalogue of encountered listing summaries; signing out clears it. The test app does not import the original app's cookies or history.
